# Frontend style guide

`src/app.css` defines the shared typography, theme colors, and component classes. Use those classes and the shared Svelte components for new screens, including admin pages. When a style changes, update its shared definition, review all uses across public pages, admin pages, and dialogs, and update this guide in the same change.

## Typography

Use JetBrains Mono throughout. Keep interface labels in the site's lowercase style and preserve the capitalization of names and titles supplied by users or APIs.

| Role | Class or element | Size |
| --- | --- | --- |
| Home display title | `h1.text-display` | 36 px, 48 px from `lg` |
| Page title | `h1` or `text-page-title` | 30 px, 36 px from `sm` |
| Section title | `h2` or `text-section-title` | 20 px, 24 px from `sm` |
| Subsection and card title | `h3`–`h6` or `text-card-title` | 16 px, 18 px from `sm` |
| Normal text and field values | Body default or `text-body` | 14 px, 16 px from `sm` |
| Subtitle and secondary text | `subtitle` or `text-secondary` | 14 px |
| Compact media title | `compact-media-title` | 14 px |
| Compact media subtitle | `compact-media-subtitle` | 12 px |
| Compact metadata, dates, and tags | `text-meta` | 12 px |

Keep featured media cards at the standard card-title and subtitle sizes. Use the compact media styles for smaller cover cards. Compact titles stay on one line with an ellipsis when they run out of space. Keep the complete title in the markup and in a title tooltip.

Use `CustomH1` or `H1WithBreadCrumb` for page titles and `CustomH2` for green section headings with optional subtitles. Media group labels use `ColoredSectionTitle` with yellow for in-progress groups and green for completed groups. The member calendar uses 16 px bg0 text and standard strip padding for its H3 headings, with aqua for the month range, yellow for events, and green for comments. Individual month labels appear when multiple months are visible and use bg1, with a purple background for the current month. Match the month navigation buttons to the range strip height. Use `SectionSeparator` for a full-width, 2 px `bg2` rule with 32 px of margin above and below. Pass grid span classes from the parent layout and use the component margins to space adjoining sections. Use `CustomH3` for actual subsections. Use blue text for H1, green text for H2, and filled strips with bg0 text for H3. Use aqua as the default H3 fill. Use `fieldset` and `legend.section-label.field-group-label` for Motorsport pick groups. They use the 14 px media-strip treatment, with purple for qualifying and green for races. Use `text-section-title` for Motorsport page headings and `text-card-title` for its section headings. Carousel meeting names and status tags use 14 px text.

## Color

- Use the active theme's tokens. `bg-bg0` is the page background, `bg-bg1` is a surface, `bg-bg2` is a hover state, and `bg-bg3` is a border, divider, or neutral tag background. Use `text-fg0` for content and `text-gray` for supporting copy. Apply `text-fg0` directly to each theme preview item so its label and icons use the palette shown by that item.
- Blue marks page titles and accent actions. Green marks section titles, primary saves, and success. Red marks errors and destructive actions. Yellow marks warnings and in-progress media. Purple marks keyboard focus, external links, and editing highlights.
- Preserve meaningful accents on navigation cards and domain data, including team colors, game tiles, and scoring. Use accompanying text, labels, or tooltips wherever color encodes meaning. Use `text-bg0` on solid theme-colored backgrounds.
- Use `ThemeColorSelect` for fields that select from the site palette. Show swatches in the trigger and options, with color names available to assistive technology.
- Keep section accents in `page-colors.ts`. Use purple for admin, aqua for calendar, green for games, yellow for media, gray for motorsport, red for notifications, and blue for pics and users. Notification group toggles use a muted section color when unselected and a solid section color when selected. Use `SettingsSwitch` for notification and CRT settings. It has a borderless bg3 track with a 3 px inset, a green thumb when on, and a light neutral thumb when off. Labels use fg0 when on and muted gray when off. Use compact notification actions and switches below `sm`.
- Use the named palette in `src/lib/utils/profile-colors.ts` for user colors. Render a validated saved color through its theme variable, such as `var(--blue)`, so the same preference adapts to every theme.
- Wrap ordinary internal navigation labels in square brackets. Use `internal-link` for muted utility navigation, with the active header or home link in `fg0`. In the hamburger menu, links use `text-gray` by default and use `fg0` on their page or its subpages. Use `external-link` for all outbound links, which stay purple and underlined. Prefer semantic tokens to raw hex values in components.

## Components

Use the bold Phosphor weight for site icons. The root layout provides it for all routes and popups.

| Pattern | Shared styles |
| --- | --- |
| Cards | `surface-card` for content, `surface-card-hover` for clickable surfaces, `card-link` for navigation cards with matching left accent borders and title colors. Use `AdminSectionCard` for admin navigation. It puts a 16 px bg0 icon inside a 28 px square to the left of the title. Subpage cards use the parent section’s color. |
| Lists | `surface-list` and `list-row` for management rows, `card-list` for spaced lists of cards. Separate rows with an 8 px gap. Use `UserAvatar` for user rows and group related actions. Calendar access lists use green borders for members and red borders for nonmembers. Admin user rows use blue borders to match the blue role button. Calendar comment cards use 12 px padding and a square 48 px avatar beside a card-sized display name in the author’s profile color, muted posting date and time, and an `fg0` comment with a 4 px gap above it, with a 4 px right border in the author’s profile color. The comment editor uses the same avatar size and padding, with the textbox between the avatar and a square 48 px paper-plane send button. Center all three vertically. Use smaller type for comment cards and the editor below `sm`. |
| Tables | `data-table` for header and row styles, with `matrix-table` for dense standings. Put wide data tables in a horizontally scrollable wrapper. In a standings comparison, highlight only counted shared-round cells with `bg-bg1 text-fg0 font-semibold`. Rank, username, and total use the same row colors, with red for first place and blue for other selected players. |
| Labeled buttons | `button` plus `button-primary`, `button-secondary`, `button-quiet`, `button-accent`, `button-warning`, or `button-danger`. Use filled treatments for actions, with green for saves and red for cancel and delete. Secondary buttons use `bg3` and lighten to `bg4` on hover. Reserve `button-quiet` for low-emphasis controls such as header utilities. Use `DefaultButton` where its status API fits. |
| Icon actions | Filled `action-icon` with `action-icon-danger` for a red destructive action. Supply an accessible label. |
| Forms | `form-label` and `form-field` on labeled inputs and textareas. Use `FormSelect` for form dropdowns, with the site’s menu panel and item styles. Use `form-feedback` with the appropriate status color and accessible status or alert role. |
| Tags | `tag` for short statuses or metadata, with a theme color when it communicates a state. Use `tag-series` for the gray fill and `bg0` text of book series tags. |
| Tabs | Use `tab-nav` for a shared bottom divider and `tab-link` for each tab. The active tab uses bold text and a 4 px blue underline. |
| Menus and dialogs | Keep the existing interaction primitive and use `menu-panel` and `menu-item`, or `dialog-backdrop` and `dialog-panel`. Keep the visible `bg3` border on popup surfaces. Motorsport driver dropdowns use a 4 px team-color accent on the trigger and options. The qualifying time input uses the same 4 px width in purple. Use a blue dialog title, smaller green subsection headings, and a red `action-icon-danger` for the close button. |

Keep corners square. Use a 16 px default card inset and a 16 px gap between panels. Use 8 px gaps between closely related controls or cards in a list. Standard buttons and icon actions have a 40 px minimum target. Keep visible keyboard focus and disabled states. Use `DD/MM/YYYY` for calendar dates and start calendar weeks on Monday. Use the shared `MonthPicker` for calendar views and `CalendarDateField` for editable dates. It shows four months on desktop, two on tablets, and one on mobile. Shared month pickers show six months at viewport widths of 1920 px and above and open on today unless a date is specified. Games and Games admin month range H3s use aqua text on a transparent background. Use an fg0 border for the selected date and a purple border for today. When today is selected, place the purple border inside the fg0 border. Use bg0 for ordinary dates and bg2 for dates with automatic game events. Show comments as a 6 px filled dot with a 2 px gap beneath the day number, in the same color as the number. Dates with highlighted events use the highest-priority highlighted type color for both the text and the tile tint, matching the game calendar treatment. The event type editor shows icon previews with accessible names, including an option to clear the icon. It uses an eye toggle for highlighting, with a muted crossed-out eye when off. Game calendars use their own day status colors. Calendar events use plain rows. Show the optional icon, category name, and trailing middle dot in the category color, aligned with the first line of the description. Use 12 px event text below `sm`. Automatic game summaries wrap as needed so the full result stays readable. Group automatic game events after other events. Use 16 px between the visible event groups and the add-event disclosure, and 8 px between rows within each group. The admin settings cog sits beside the events title strip and matches the month navigation buttons. Admin event and type cards use a matching 4 px left accent. Event type color selectors show theme swatches with accessible color names and reserve purple for calendar selection. Event type dropdowns show the type icon in a 28 px square filled with its color, with normal foreground text alongside. Types without an assigned icon use text alone. Align save and delete actions with the bottom edge of the event type fields. When reorder controls sit beside the fields, align them to the same edge with 2 px of bottom clearance. The member event editor is collapsed by default behind a compact add-event disclosure. Score matrices and game boards use their own sizing while sharing the typography, palette, and focus treatment. On the Games page, show both players side by side, each with their avatar, username, and score in one card. Use the shared tab navigation for daily, weekly, monthly, and global results. Daily totals count game wins. The other totals count days won. Show a points chart with a bg2 left stripe below the stats, or below the scoreboard on views without stats. Use each player’s profile color for cumulative totals and bars showing their lead above or below zero in the difference view. Label both sides of the zero line with unsigned values. On Wordle and La Palabra del Día subpages, show each player’s result distribution on Weekly, Monthly, and Global with side-by-side stats cards at all widths and equal-width tracks filled in their profile color. Below the chart, show games played, average guesses for solved puzzles, and win rate. Use the same chart cards on Isaaconnect, with arrow controls inside each card to cycle both charts through points, lives, and time. Keep attempt count and win rate visible on every chart, alongside the selected metric’s average. List points and lives in descending order and exclude attempts over ten minutes from time statistics. Outline the selected week row in Weekly. In Monthly, outline the selected month grid and fill its separate title with fg0. Use green, red, or gray for the username, card border, and tint, with a stronger tint and matching text on the score tile. Each game uses two equal result cards side by side at every screen size. Game matchup headings use the Games admin icons in filled aqua squares. Game page titles use filled blue icons. The game navigation uses aqua fills and switches the active page’s fill to fg0. Compact game result cards use the outcome tint across the card and a stronger tint for the score tile toward the center. Put each compact board in its own card with an outer border in the player’s profile color and show submitted Wordle letters where available. Use the compact player editor in place of an empty board when the signed-in player can submit today’s result. Isaaconnect puts points nearest the center and adds an icon for each visible tie-breaker. Tied metrics use gray. When both players lose, all metrics shown use red. Below the scoreboard, use the shared month picker for daily results. Tint the square and color the day number with the winner’s profile color for wins and gray for draws, using the same tint as highlighted dates on the member calendar. Verify changes at narrow and wide widths and in both themes offered by the header.
